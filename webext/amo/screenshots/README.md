# Screenshots (AMO previews)

Drop `.png` or `.jpg` files here to sync them as add-on previews on the AMO listing. Files are uploaded in name-sorted order. An optional sibling `.txt` with the same base name becomes the preview caption (`01-popup.png` + `01-popup.txt`).

With no image files present, preview sync is skipped entirely. When images exist, the listing's previews are replaced to match this directory (extra live previews are deleted).
