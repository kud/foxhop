Targets live in `~/.config/foxhop/tabs.json` (see [Configuration](/projects/foxhop/docs/configuration)). Run `foxhop init` to seed an example config.

```sh
foxhop focus chatgpt          # focus a saved target (foregrounds Firefox)
foxhop focus chatgpt --url https://chatgpt.com/c/abc   # repoint its tab there, if the target has navigate: true
foxhop focus --match figma.com --url https://figma.com   # ad-hoc, no config entry
foxhop list                   # saved targets (--json for machine output)
foxhop tabs                   # currently open Firefox tabs (--json)
foxhop add https://mail.google.com --title Gmail   # id: gmail (slug of the title)
foxhop edit gmail --url https://mail.google.com/mail/u/1   # change fields, never the id
foxhop remove gmail
foxhop sync                   # generate per-tab Raycast hotkey scripts
foxhop install                # (re)register the native messaging host manifest
```

Set `FOXHOP_BROWSER` if you don't run Firefox Nightly (e.g. `FOXHOP_BROWSER=Firefox`).

## Paste and read

`paste` fills a text box on a target's tab (hopping to it like `focus` first) and `read` prints text from it without focusing anything. Neither submits a form or presses Enter.

```sh
git diff | foxhop paste chatgpt
foxhop paste notes            # no stdin: uses the clipboard
foxhop paste docs --into "#comment"
foxhop read notes --from "article" --last
git diff | foxhop paste review && foxhop read review --last --wait > out.md
```

`paste` picks the box it fills in this order: the `--into` selector (or the target's saved `into`); else the currently focused editable element; else the largest visible textarea, text input or contenteditable element; else it fails with `no text box on that tab`. The content is replaced, never appended, and frameworks are told about it.

`read` prints each match's `innerText` as a block separated by a blank line (`--last` prints only the last). With `--wait` it polls until the text has been unchanged for 1.5 s and is non-empty, bounded by `--timeout` in seconds (default 60, cap 300).
